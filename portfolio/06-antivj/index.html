Élytre AntiVJ

Under the creative direction of AntiVJ and in collaboration with Simon Geilfus, I developped a bespoke Cinder application to author and continuously generate unique lighting patterns on the Flow’s illumination system in Paris.

The precise location of each pixel in 3d space is used to sample volume noise fields. The resulting noise values are in turn used to sample images. This generates abstract color layers which can be composited together using Photoshop-style methods, and faded in/out over time.

An array of sensors on the building itself can also affect change, depending on how the user connects their values to visual parameters.
